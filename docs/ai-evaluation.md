# ประเมิน AI ในเกม NIKI

ชุดนี้เรียก Gemini API จริง โดยใช้ข้อความคดีสมมติจากโปรเจกต์และโค้ดวิเคราะห์เดียวกับเกม ประกอบด้วยคำถาม 10 ข้อและการสร้างไทม์ไลน์ 1 ข้อ ครอบคลุมข้อมูลรายไฟล์ การเปรียบเทียบสองไฟล์ และคำถามที่หลักฐานไม่ระบุคำตอบ

## วิธีรันใน PowerShell

1. เปิด Terminal ในโฟลเดอร์โปรเจกต์และตั้ง API Key เฉพาะในหน้าต่างนั้น โดยไม่ส่งคีย์ในแชตหรือบันทึกลงไฟล์:

   ```powershell
   $nikiKeyInput = Read-Host 'Gemini API Key' -AsSecureString
   $env:NIKI_GEMINI_API_KEY = [System.Net.NetworkCredential]::new('', $nikiKeyInput).Password
   Remove-Variable nikiKeyInput
   ```

2. หากต้องการกำหนดโมเดลเอง ให้ตั้งชื่อตามที่บัญชีของคุณใช้งานได้ ตัวอย่าง:

   ```powershell
   $env:NIKI_GEMINI_MODEL = 'gemini-3.5-flash-lite'
   ```

   ถ้าไม่ระบุ จะใช้ `gemini-3.5-flash-lite` ชุดประเมินปิดการสลับโมเดลอัตโนมัติ เพื่อให้รายงานระบุโมเดลที่เรียกได้ตรง

3. รันชุดประเมิน:

   ```powershell
   npm run evaluate:ai
   ```

   ชุดประเมินส่งคำขอจริง 11 ครั้งตามลำดับ จึงใช้โควตาของบัญชีและอาจมีค่าใช้จ่ายตามแผน รายงานจะถูกสร้างในโฟลเดอร์ `reports/` โดยไม่บันทึก API Key หากไม่มีคีย์ โปรแกรมจะแจ้งและหยุดโดยไม่สร้างผลทดสอบปลอม

4. เปิดรายงานแล้วตรวจคำตอบและแหล่งอ้างอิงด้วยตนเองทุกข้อ จากนั้นเลือกช่องถูกต้อง / ไม่ถูกต้อง / ไม่แน่ใจ เพื่อใช้ประกอบการนำเสนอ

5. เมื่อตรวจเสร็จ ลบตัวแปรคีย์ออกจากหน้าต่าง Terminal นี้:

   ```powershell
   Remove-Item Env:NIKI_GEMINI_API_KEY
   ```

ตัวบ่งชี้อัตโนมัติตรวจคำตอบที่ผ่านการตรวจและจัดรูปแบบโดยระบบแล้ว โดยตรวจเพียงคำ เวลา ชื่อไฟล์ และรูปแบบ ไม่ใช่คะแนนความแม่นยำของผลดิบจาก AI แม้ข้อความอ้างอิงมีอยู่ในไฟล์ ก็ยังต้องตรวจว่าข้อสรุปตีความถูกต้องหรือไม่ ผลอาจต่างกันระหว่างแต่ละครั้ง

สำหรับชุดทดสอบที่ไม่เรียก API จริง ใช้ `node --test tests/*.test.js` ซึ่งรวมการจำลอง API เพื่อทดสอบการเชื่อมต่อ การตรวจแหล่งอ้างอิง และการจัดเรียงไทม์ไลน์

อ้างอิง: [Gemini API — การเรียก generateContent](https://ai.google.dev/gemini-api/docs/generate-content/text-generation) และ [การตรวจ structured output](https://ai.google.dev/gemini-api/docs/structured-output)
